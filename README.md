# TDSK_Parser

Осуществляется анализ выгрузки уникальных квартир в экспозиции застройщика ТДСК за второе полугодие 2023 года в том виде, в каком они приходят с первоисточника
из файла `Экспозиция ТДСК с 01.07.2023 по 31.12.2023 (1).csv`. Создается сводная таблица в файле `actual_table.xlsx`,  в которой указано по корпусам количество актуальных квартир на каждый день с 1 июля по 31 декабря 2023 года. Затем создается график график по месячному количеству активных объектов в разрезе комнатности:
<img width="1283" height="678" alt="image" src="https://github.com/user-attachments/assets/7a5375fc-d0ba-45bd-aff8-27f110965aac" />
По этому графику можно понять, что однокомнатные квартиры во втором полугодии 2023 года были наиболее актуальны судя по их количеству и темпам продажи. С июля по август
фиксировался рост количества однокомнатных, двухкомнатных и трехкомнатных квартир, начиная с осени они продавались. Менее актуальными оказались трехкомнатные квартиры, в наименьшей степени актуальными оказались двукомнатные квартиры, по их количеству и темпам продажи они уступили трехкомнатным и в значительной степени однокомнатным.

Выборка была расширена квартирами, размещенных на сайте по ссылке https://www.t-dsk.ru/buildings/search-apartments/?objects=all. Для сравнения количеств квартир по количеству комнат, площади и стоимости в старой и расширенной выборках создаются линейчатые диаграммы.

## Инструкция по запуску проекта

1.  Склонируйте репозиторий себе на компьютер:
```bash
git clone https://github.com/DekDanD/TDSK_Parser.git
cd TDSK_Parser
```
2.  Установите зависимости:
```bash
pip install -r requirements.txt
```
3.  Запустите `main.py`
```bash
python main.py
```
